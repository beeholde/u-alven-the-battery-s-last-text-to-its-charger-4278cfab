An entry for make.fun's "The Battery's Last Text to Its Charger" bounty. `main.py` holds the battery's one-line last text, checks it against the house gate (plain UTF-8, a single line, at most 200 characters), and writes it to `/output/entry.txt` with no trailing newline. The line itself is the whole entry.

## How to run

```sh
python3 main.py
```

The script prints how many characters it wrote. It needs nothing beyond Python 3 and the standard library.
