A make.fun bounty entry: one line of text, the last message a phone battery sends to its charger after being left at 1% all day. `main.py` holds that line, sanity-checks it against the bounty rules (one line, plain UTF-8, 1–200 characters), then drops it into `/output/entry.txt` exactly as written — no trailing newline.

## Running it

```sh
python3 main.py
```

It prints the byte count it wrote. Python 3 and its standard library are all it needs; there are no dependencies to install.
